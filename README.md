# AI Smart Expense Tracker

An AI-powered expense tracking application designed to help users manage expenses, monitor budgets, analyze spending patterns, and make smarter financial decisions.

## Features

- **Expense Tracking** — Record and manage daily transactions.
- **Spending Analysis** — Understand spending habits and expense categories.
- **Budget Monitoring** — Track expenses against budget limits.
- **Financial Goals** — Set and monitor personal financial goals.
- **Investment Suggestions** — Explore investment-related recommendations.
- **Transaction History** — Review previous transactions.
- **CSV Upload** — Import transaction data.
- **AI-Powered Financial Insights** — Support smarter financial planning and spending decisions.

## Technology Stack

- **Frontend:** React.js, JavaScript, CSS
- **Backend:** Python, Flask
- **Database:** SQLite
- **Data Analysis:** Python

## Getting Started

1. Clone this repository.
2. Install the required frontend and backend dependencies.
3. Configure the application settings and environment variables.
4. Start the Flask backend.
5. Start the React frontend.
6. Open the local URL displayed by the frontend development server.

For detailed instructions, refer to [HOW_TO_RUN.md](HOW_TO_RUN.md).

## Security

Do not commit API keys, passwords, personal financial information, or local database files.
